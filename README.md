# NoFakeCam (위조방지 카메라)

AI 조작 걱정 없는 진짜 사진 인증 카메라.


[촬영하기]를 누르면 휴대폰 기본 카메라가 열리고, 찍은 사진의 픽셀에 눈에 보이지 않는 워터마크(앱 공통 패턴 + 촬영 시각)를 새겨 앨범에 저장하는 웹 앱입니다. [사진 확인하기]로 어떤 사진이 이 앱으로 찍은 것인지 확인합니다.

- 저장: 안드로이드는 자동 다운로드(갤러리 › Download), iOS는 공유 창의 ‘이미지 저장’(웹은 앨범에 직접 쓸 수 없어 한 번 탭 필요)
- 갤러리 사진은 거부(파일 시각이 10분 이상 지난 경우) — 카메라로 방금 찍은 사진만 워터마크

## 워터마크 구조 (`src/lib/watermark.ts`)

| 층 | 방식 | 픽셀 변화 | 살아남는 경우 |
|---|---|---|---|
| 타일 무늬 | 32×32칸 의사난수 ±1 타일을 사진 전체에 반복 (칸 = 긴 변/256, 타일 = 긴 변/8). 절반은 고정 동기 무늬, 절반은 촬영 시각(분)+CRC16 | ±1.5~4 (질감 많은 곳일수록 강하게) | 메신저 전송(크기 축소·JPG 재압축), 크롭, 비율 변경, 90° 회전, 밝기 보정 |
| 픽셀 층 | 파란 채널 최하위 비트 | ±1 | PNG 원본만 — 남아 있으면 "원본 파일 그대로" |

확인 과정: 고주파 밝기 → 행/열 자기상관에서 타일 주기(가로·세로 따로) → 주기로 접어 타일을 겹침 → FFT 상관으로 시작 위치·회전 → 데이터 칸에서 시각. 실패하면 1/2, 1/4 크기로 다시 시도(큰 크롭 대응). 타일마다 국소 상관(z ≥ 3)을 계산해 사진 위에 근거 레이어로 표시 — 편집해서 붙여넣은 부분은 무늬가 비어 보임.

판정 기준: 동기 무늬 PSR ≥ 8 (워터마크 없는 실제 사진 57건에서 최대 5.8). 시각은 CRC가 맞을 때만 표시.

측정 (scikit-image 실제 사진 4장 × 15가지 변형): 53/60 인식, 오판 0/57. 실패는 원본의 1/16만 남긴 크롭, 흰 배경이 대부분인 사진의 크롭.

## 개발

```bash
npm install
npm run dev
```

카메라(getUserMedia)는 HTTPS 또는 localhost에서만 동작합니다.

## iOS 앱 (Capacitor)

웹과 같은 코드(`out/` 정적 빌드)를 앱에 넣고, 앱에서만 두 가지가 달라집니다.

- [촬영하기] → 앱 안 전체 화면 카메라(`@capacitor-community/camera-preview`). 셔터를 누르면 "Use Photo" 확인 없이 바로 처리
- 저장 → 사진 앱에 PNG 그대로 저장(`@capacitor-community/media`, 사진 추가 전용 권한). PNG라 앨범의 사진도 "원본 파일 그대로"로 검증됨

Mac(Xcode 필요)에서:

```bash
git pull
npm install
npm run ios        # next build → cap sync ios → Xcode 열림
```

Xcode에서: 왼쪽 `App` 프로젝트 → `App` 타깃 → Signing & Capabilities → Team에 Apple ID 선택 → 상단 기기 목록에서 연결한 아이폰 선택 → ▶ 실행.
처음 설치하면 아이폰 설정 › 일반 › VPN 및 기기 관리에서 개발자 앱을 신뢰해야 열립니다. 아이폰 설정 › 개인정보 보호 및 보안 › 개발자 모드도 켜야 합니다.

- 앱 ID: `kr.nofakecam.app` (`capacitor.config.ts`) — 첫 스토어 제출 전까지 변경 가능
- 권한 문구: `ios/App/App/Info.plist` (카메라, 사진 추가)
- 웹 코드를 바꾼 뒤에는 `npm run cap:sync` 후 Xcode에서 다시 실행
