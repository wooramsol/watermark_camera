# 워터마크 카메라

브라우저에서 사진을 찍는 순간, 눈에 보이지 않는 워터마크(문구 + 촬영 시각)를 사진 픽셀에 새기는 웹 앱입니다.

## 워터마크 구조 (`src/lib/watermark.ts`)

| 층 | 방식 | 픽셀 변화 | 살아남는 경우 |
|---|---|---|---|
| 픽셀 워터마크 | 파란 채널 최하위 비트(LSB), 키 기반 의사난수로 분산 | ±1 | PNG 원본만 — 남아 있으면 "원본 그대로"의 증거 |
| 보조 워터마크 | 8×8 블록 평균 밝기 QIM | 최대 ±2 | JPG 재압축(품질 60 이상 확인) |

- 프레임: 버전 · 길이 · 유닉스 시각 · 문구(최대 40바이트, UTF-8) · CRC32, 사진 전체에 반복 → 다수결로 복원
- 비밀 키를 정하면 같은 키로만 읽힘 (기본 키는 공개)
- 크기 변경·자르기에는 두 층 모두 지워짐

## 개발

```bash
npm install
npm run dev
```

카메라(getUserMedia)는 HTTPS 또는 localhost에서만 동작합니다.
