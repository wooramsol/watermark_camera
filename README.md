# 워터마크 카메라

[촬영하기]를 누르면 휴대폰 기본 카메라가 열리고, 찍은 사진의 픽셀에 눈에 보이지 않는 워터마크(앱 공통 패턴 + 촬영 시각)를 새겨 앨범에 저장하는 웹 앱입니다. [사진 확인하기]로 어떤 사진이 이 앱으로 찍은 것인지 확인합니다.

- 저장: 안드로이드는 자동 다운로드(갤러리 › Download), iOS는 공유 창의 ‘이미지 저장’(웹은 앨범에 직접 쓸 수 없어 한 번 탭 필요)
- 갤러리 사진은 거부(파일 시각이 10분 이상 지난 경우) — 카메라로 방금 찍은 사진만 워터마크

## 워터마크 구조 (`src/lib/watermark.ts`)

| 층 | 방식 | 픽셀 변화 | 살아남는 경우 |
|---|---|---|---|
| 픽셀 워터마크 | 파란 채널 최하위 비트(LSB), 키 기반 의사난수로 분산 | ±1 | PNG 원본만 — 남아 있으면 "원본 그대로"의 증거 |
| 보조 워터마크 | 8×8 블록 평균 밝기 QIM | 최대 ±2 | JPG 재압축(품질 60 이상 확인) |

- 프레임: 버전 · 유닉스 시각 · CRC32 (9바이트), 사진 전체에 반복 → 다수결로 복원
- 모든 사진이 같은 고정 패턴(개인 키 없음). `SEED`를 바꾸면 이전 사진을 못 읽으니 바꾸지 말 것
- "원본 그대로" 판정은 픽셀 층 일치도 98% 초과일 때만 (JPG 사본도 다수결로 픽셀 층이 읽힐 수 있음)
- 크기 변경·자르기에는 두 층 모두 지워짐

## 개발

```bash
npm install
npm run dev
```

카메라(getUserMedia)는 HTTPS 또는 localhost에서만 동작합니다.
